## GitHubへ入れる手順（VS Codeから）

このVMからの GitHub ログイン連携が難しいため、GitHub への登録は VS Code から行う想定（2026-11-06 決定）。

1. このフォルダを展開して VS Code で開く（`.git` ごと入っているので履歴もそのまま使える）
2. VS Code のソース管理で「Publish to GitHub」→ 非公開（Private）リポジトリとして公開する
   - リポジトリ名の想定：`okinawa-bassai-center`
3. 以後のデザイン更新は、このフォルダの `index.html` を差し替えてコミットする
